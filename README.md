## Description

This project is a Library Management System built using Python. It manages a catalogue of books and a register of members, allowing members to borrow and return books while following library borrowing rules.

## How to Run

python library.py

## Features 

- Add book to the library 
- Register a member 
- Borrow a book 
- Return a book 
- Search the catalogue 
- View the summary of a member 
- View the library report 
- Exit the program
